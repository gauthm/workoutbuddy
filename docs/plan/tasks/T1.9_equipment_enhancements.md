## Contexte — modèle de données des nouvelles catégories

### `dumbbell_loadable` — Poignée d'haltère à disques

```
Représente UNE PAIRE de poignées d'haltères à disques.
  weight_kg = poids d'UNE poignée (ex: 2.0 kg)
  count     = 2 (toujours — une paire, verrouillé en frontend)

Charge par haltère = weight_kg + somme des disques sur un côté × 2
  → même calcul que barre + plaques, mais par haltère individuel

Exemple :
  Poignée 2 kg + disque 1 kg × 1 côté + disque 0.5 kg × 1 côté
  = 2 + 2×(1+0.5) = 5 kg par haltère
```

### `dumbbell_plate` — Disque spécifique haltère

```
Disque qui NE VA PAS sur une barre (taille de perçage différente, etc.)
  weight_kg = poids du disque (ex: 0.5, 1, 1.25, 2.5 kg)
  count     = quantité totale — DOIT être pair (paires par côté = count / 2)

Utilisé uniquement avec dumbbell_loadable.
La catégorie 'plate' peut être partagée entre barres ET haltères.
```

### `bench_adjustable` — Banc réglable/inclinable

```
Banc qui peut être mis en position plate, inclinée (ex: 30°, 45°, 60°) et déclinée.
Pas de champ poids ni count.

Règle de sous-type :
  bench_adjustable satisfait 'bench'
  → un exercice qui requiert 'bench' est réalisable avec 'bench_adjustable'
```

```javascript
/**
 * Calcule toutes les charges atteignables avec l'inventaire donné.
 *
 * Catégories prises en compte :
 *   barbell / ez_bar      + plate          → calcul barre + plaques
 *   dumbbell_loadable     + plate / dumbbell_plate → calcul poignée + disques
 *   dumbbell_fixed                         → charge fixe (par paire)
 *   dumbbell_adjustable                    → plage par pas
 *
 * @param {object[]} equipmentItems - EquipmentItem[]
 * @param {object}   exercise       - { equipment_required: string[], is_unilateral: 0|1 }
 * @returns {{ loads_kg: number[], min_increment_kg: number, max_load_kg: number }}
 */
export function calculateAchievableLoads(equipmentItems, exercise) {
  const eqTypes      = exercise.equipment_required || []
  const isUnilateral = exercise.is_unilateral === 1

  // Exercice sans équipement requis
  if (eqTypes.length === 0) {
    return { loads_kg: [0], min_increment_kg: 0, max_load_kg: 0 }
  }

  const all_loads = new Set()

  // ── 1. Barres + disques de barre ────────────────────────────
  const barbells = equipmentItems.filter(i =>
    ['barbell', 'ez_bar'].includes(i.category) &&
    eqTypes.includes(i.category)
  )
  if (barbells.length > 0) {
    // Disques compatibles avec les barres : 'plate' uniquement (pas dumbbell_plate)
    const barPlatePairs = equipmentItems
      .filter(i => i.category === 'plate')
      .map(i => ({ weight: i.weight_kg, max: Math.floor((i.count || 0) / 2) }))
      .filter(p => p.max > 0 && p.weight > 0)

    const perSide = dpSubsetSum(barPlatePairs)
    for (const bar of barbells) {
      for (const s of perSide) {
        all_loads.add(
          round2(isUnilateral ? bar.weight_kg + s : bar.weight_kg + 2 * s)
        )
      }
    }
  }

  // ── 2. Haltères à disques (dumbbell_loadable) ───────────────
  // Un exercice qui requiert dumbbell_fixed ou dumbbell_loadable
  // peut être réalisé avec des poignées à disques.
  const exerciseNeedsDumbbells =
    eqTypes.includes('dumbbell_loadable') ||
    eqTypes.includes('dumbbell_fixed') ||
    eqTypes.includes('dumbbell_adjustable')

  const dumbHandles = exerciseNeedsDumbbells
    ? equipmentItems.filter(i => i.category === 'dumbbell_loadable' && i.count >= 2)
    : []

  if (dumbHandles.length > 0) {
    // Disques pour haltères : 'plate' + 'dumbbell_plate'
    const dumbPlatePairs = equipmentItems
      .filter(i => i.category === 'plate' || i.category === 'dumbbell_plate')
      .map(i => ({ weight: i.weight_kg, max: Math.floor((i.count || 0) / 2) }))
      .filter(p => p.max > 0 && p.weight > 0)

    const perSide = dpSubsetSum(dumbPlatePairs)
    for (const handle of dumbHandles) {
      for (const s of perSide) {
        // Charge par haltère = poids poignée + disques des 2 côtés
        all_loads.add(round2(handle.weight_kg + 2 * s))
      }
    }
  }

  // ── 3. Haltères fixes ────────────────────────────────────────
  if (exerciseNeedsDumbbells) {
    equipmentItems
      .filter(i => i.category === 'dumbbell_fixed' && i.count >= 2)
      .forEach(i => all_loads.add(round2(i.weight_kg)))
  }

  // ── 4. Haltères réglables (sélecteur) ───────────────────────
  if (exerciseNeedsDumbbells) {
    equipmentItems
      .filter(i => i.category === 'dumbbell_adjustable')
      .forEach(i => {
        let w = i.weight_min_kg
        while (w <= i.weight_max_kg + 0.001) {
          all_loads.add(round2(w))
          w = round2(w + i.weight_step_kg)
        }
      })
  }

  // ── 5. Trier + incrément minimal ────────────────────────────
  const sorted = Array.from(all_loads).sort((a, b) => a - b)
  if (sorted.length === 0) {
    return { loads_kg: [], min_increment_kg: 0, max_load_kg: 0 }
  }

  let minInc = Infinity
  for (let i = 1; i < sorted.length; i++) {
    const d = round2(sorted[i] - sorted[i - 1])
    if (d > 0.001) minInc = Math.min(minInc, d)
  }

  return {
    loads_kg:         sorted,
    min_increment_kg: sorted.length <= 1 ? 0 : (minInc === Infinity ? 0 : minInc),
    max_load_kg:      sorted[sorted.length - 1],
  }
}

// ── Helper : DP bounded subset sum ──────────────────────────
// Retourne un Set de toutes les sommes atteignables avec les paires de disques.
function dpSubsetSum(platePairs) {
  let current = new Set([0])
  for (const { weight, max } of platePairs) {
    const next = new Set(current)
    for (const s of current) {
      for (let k = 1; k <= max; k++) {
        next.add(round2(s + k * weight))
      }
    }
    current = next
  }
  return current
}

// ── Helper : arrondi 2 décimales ─────────────────────────────
function round2(n) {
  return Math.round(n * 100) / 100
}

// ── Export roundDownToAchievable (inchangé) ──────────────────
export function roundDownToAchievable(targetWeight, achievableLoads) {
  if (!achievableLoads || achievableLoads.length === 0) return 0
  const valid = achievableLoads.filter(l => l <= targetWeight + 0.001)
  if (valid.length === 0) return achievableLoads[0]
  return valid[valid.length - 1]
}
```

```javascript
/**
 * Vérifie si un exercice est réalisable avec l'inventaire disponible.
 * Applique les règles de sous-type :
 *   bench_adjustable satisfait 'bench'
 *   dumbbell_loadable satisfait 'dumbbell_fixed'
 *   dumbbell_fixed / dumbbell_adjustable / dumbbell_loadable satisfait 'dumbbell'
 *
 * @param {string[]} equipmentRequired - liste des catégories requises par l'exercice
 * @param {object[]} equipmentItems    - inventaire complet
 * @returns {boolean}
 */
function isEquipmentAvailable(equipmentRequired, equipmentItems) {
  if (!equipmentRequired || equipmentRequired.length === 0) return true

  // Construire l'ensemble des catégories disponibles avec sous-types
  const available = new Set(equipmentItems.map(i => i.category))

  // bench_adjustable → satisfait bench
  if (available.has('bench_adjustable')) available.add('bench')

  // dumbbell_loadable → satisfait dumbbell_fixed
  if (available.has('dumbbell_loadable')) available.add('dumbbell_fixed')

  // Toute forme d'haltère → satisfait les autres formes pour la disponibilité
  if (
    available.has('dumbbell_fixed') ||
    available.has('dumbbell_adjustable') ||
    available.has('dumbbell_loadable')
  ) {
    available.add('dumbbell_fixed')
    available.add('dumbbell_adjustable')
    available.add('dumbbell_loadable')
  }

  return equipmentRequired.every(req => available.has(req))
}
```

```javascript
async function save() {
  if (!form.name.trim()) {
    store.showToast('Le nom est obligatoire.', 'error')
    return
  }

  // Validation count pair pour plate et dumbbell_plate
  if (['plate','dumbbell_plate'].includes(form.category)) {
    const n = parseInt(form.count) || 0
    if (n < 2 || n % 2 !== 0) {
      store.showToast('Les disques doivent être en quantité paire (ex: 2, 4, 6).', 'error')
      return
    }
  }

  // Forcer count=2 pour dumbbell_loadable
  if (form.category === 'dumbbell_loadable') {
    form.count = 2
  }

  // Validation haltère réglable
  if (form.category === 'dumbbell_adjustable') {
    if (!form.weight_min_kg || !form.weight_max_kg || !form.weight_step_kg) {
      store.showToast('Renseigner poids min, max et incrément.', 'error')
      return
    }
    if (parseFloat(form.weight_min_kg) >= parseFloat(form.weight_max_kg)) {
      store.showToast('Le poids minimum doit être inférieur au maximum.', 'error')
      return
    }
  }

  saving.value = true
  try {
    // Nettoyer les champs vides → null
    const body = {}
    for (const [k, v] of Object.entries(form)) {
      body[k] = (v === '' ? null : v)
    }
    if (props.item) {
      await api.update(props.item.id, body)
    } else {
      await api.create(body)
    }
    emit('saved')
  } catch (err) {
    store.showToast(err.message, 'error')
  } finally {
    saving.value = false
  }
}
```

## Exemples chiffrés de vérification

### Exemple 1 — Haltères à disques

```
Inventaire :
  dumbbell_loadable  : "Poignée haltère" weight_kg=2, count=2
  dumbbell_plate     : "Disque 0.5kg"   weight_kg=0.5, count=8  (4 paires/côté)
  dumbbell_plate     : "Disque 1kg"     weight_kg=1,   count=8  (4 paires/côté)
  dumbbell_plate     : "Disque 1.25kg"  weight_kg=1.25,count=4  (2 paires/côté)
  dumbbell_plate     : "Disque 2.5kg"   weight_kg=2.5, count=4  (2 paires/côté)

DP par côté :
  {0} → +0.5kg ×4 → {0, 0.5, 1, 1.5, 2}
       → +1kg  ×4 → {0, 0.5, 1, ..., 6}    (par pas de 0.5)
       → +1.25 ×2 → {0, ..., 8.5}
       → +2.5  ×2 → {0, ..., 13.5}

Charges par haltère = 2 + 2×{0..13.5} :
  Minimum : 2 kg (poignée nue)
  Maximum : 2 + 2×13.5 = 29 kg
  Incrément minimal : 2×0.5 = 1 kg
  Charges : 2, 3, 4, 4.5, 5, 5.5, 6, 6.5, 7, 7.5, 8, 8.5, ... 29 kg
```

### Exemple 2 — Disques partagés barre + haltères

```
Inventaire :
  barbell            : "Barre" weight_kg=7, count=1
  dumbbell_loadable  : "Poignée" weight_kg=2, count=2
  plate              : "Disque 2.5kg" weight_kg=2.5, count=4  (2 paires)
  plate              : "Disque 5kg"   weight_kg=5,   count=4  (2 paires)

Les disques 'plate' sont utilisés POUR LES DEUX :
  Barre DP/côté  : {0, 2.5, 5, 7.5, 10}
  Barre charges  : 7+2×{0..10} = {7, 12, 17, 22, 27} kg

  Haltère DP/côté : {0, 2.5, 5, 7.5, 10}
  Haltère charges : 2+2×{0..10} = {2, 7, 12, 17, 22} kg

Résultat combiné (exercice requiert barbell) :
  loads_kg = [7, 12, 17, 22, 27]  ← incrément = 5 kg

Résultat (exercice requiert dumbbell_fixed ou dumbbell_loadable) :
  loads_kg = [2, 7, 12, 17, 22]   ← incrément = 5 kg
```

### Exemple 3 — bench_adjustable satisfait bench

```
Inventaire : bench_adjustable  (pas de bench plat)
```
